# Red Alert target for v0.7.5

The requested next phase is a visual game selector at launch, leading to either Tiberian Dawn or Red Alert. Red Alert needs Allied and Soviet campaigns, skirmish, and multiplayer. The selector should make the active game obvious, keep save files and settings associated with the correct game, and retain the current Tiberian Dawn entry point.

Before implementing or packaging it, inventory the existing Red Alert executable support, faction art, movie/audio data, campaign files, save format, and multiplayer transport. Missing Soviet or Allied imagery can be requested from the owner by exact filename/role; supplied images must be checked against the game palette, dimensions, and menu states. Compile and installation alone will not verify campaign progression or multiplayer sessions.

The first iOS engine and original-CD data inventory is recorded in [the integration status](RED-ALERT-0.7.5-INTEGRATION.md). The combined launcher and runtime verification remain open.
