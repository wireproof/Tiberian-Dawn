v0.7.4 · iOS build 710

Duo laptop layout, radar navigation, production status, and Remastered graphics refinements. The public IPA is build 710. The owner later verified the build 711 correction for duplicate Laptop/Remastered deck buttons with Duo screenshots. Build 712 changes the Cheats switch layout and awaits device testing. iPad gameplay was not separately retested for these builds.

  • Complete unsigned IPA with classic game data, music, and Remastered art.
  • Update over the existing app to preserve local saves.
  • Duplicate deck buttons are visually verified fixed in build 711; waypoint persistence and Force Move/crushing need separate verification.
