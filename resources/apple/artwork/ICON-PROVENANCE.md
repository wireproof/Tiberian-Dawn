# App icon artwork — 2026-10-26

Generated with the built-in image generation tool from user-provided Command & Conquer logo references. These are fan-project interpretations; original faction marks remain their respective owners’ property.

Active assets live in ../Assets.xcassets: AppIcon (default), AppIconGDI, AppIconNod, plus corresponding Preview image sets. All use opaque dark backgrounds. Allied/Soviet are deferred at the user’s request.

Prompt specifications:
- Default: faithfully remaster the supplied concentric metal badge, red double C arcs open right, orange-gold geometric center; preserve silhouette and proportions; opaque charcoal background, no text.
- GDI: isolate the lower-left reference badge; preserve angular abstract eagle, closed circular gold rim and silver metal backing; opaque charcoal background.
- Nod: isolate lower-right reference badge; preserve rounded black scorpion segments and tapered irregular six-sided red shield with silver border; opaque charcoal background.

Generated masters were resized to 1024×1024 for asset-catalog packaging. iOS uses Apple alternate-icon APIs; macOS changes only its runtime Dock icon without modifying the signed bundle.
